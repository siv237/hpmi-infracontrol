# Редактор дерева серверов (п.8 ROADMAP)

Структура дерева «Серверы» редактируется из UI: группы, корни-организации,
перемещение серверов, паспорт группы. Всё хранится локально (вне git):
`servers.json` (поля у серверов) + `ui.json` (объявления).

## Модель данных

Сервер (`data/servers.json`, `server/store.js`):
- `root` — имя корня-организации; `''`/`null` = корень по умолчанию
  (его имя — `ui.json:rootName`).
- `group` — имя группы в корне; `''`/`null` = **авто-филиал** по двум
  первым октетам IP («Филиал N.N», не-IP → «Филиал прочие»).

Объявления (`data/ui.json`, только через API, admin):
- `rootName` — имя корня по умолчанию.
- `roots: []` — дополнительные корни-организации.
- `groups: [{root, name, desc?, loc?, owner?, contact?, notes?}]` —
  группы; могут быть пустыми (без серверов) и нести «паспорт»
  (назначение/адрес/ответственный/контакты/заметки).

Дерево = смесь: объявленные корни/группы + фактические по серверам.

## API

- `GET /api/ui` — rootName, roots, groups (вход не требует admin).
- `PUT /api/ui` (admin): `{rootName}`, `{addRoot}`, `{delRoot}`,
  `{renameRoot:{from,to}}`, `{addGroup:{root,name}}`,
  `{delGroup:{root,name}}`, `{renameGroup:{root,from,to}}`,
  `{setGroupMeta:{root,name,meta:{desc,loc,owner,contact,notes}}}` —
  setGroupMeta создаёт объявление, если его не было (так описывается
  авто-филиал); renameFrom не поддерживает — имя меняется только
  вместе с метой через `name`.
- `PUT /api/servers/:id {group, root}` — перемещение сервера
  (drag&drop, модалка, контекстное меню).

## Фронт

- `web/js/tree.js` — рендер дерева (корни → группы → серверы),
  контекстное меню (правая кнопка на сервере/группе/корне/свободном
  поле), drag&drop, `uiStructureChanged()` — единая точка обновления
  после ЛЮБОГО изменения структуры (дерево + вкладка «Группы», если
  открыта — без F5).
- `web/js/groups.js` — вкладка «Группы»: доска корней карточками,
  группы со счётчиками (авто-филиалы отдельным блоком), паспорт,
  раскрытие списка серверов, клик по серверу → «Серверы» + select.
- `web/js/tree-controls.js` — модал сервера: поля «Корень
  (организация)» и «Филиал / группа» (автодополнение по группам
  выбранного корня).

## Грабли (уже наступлено)

- **Контекстное меню «не работает»/«не закрывается»**: закрыватели
  (`mousedown`/`contextmenu`/`keydown` на document) нельзя подписывать
  синхронно — тот же contextmenu-клик, всплыв до document, мгновенно
  закрывает меню. Решение: подписка через `setTimeout(0)` + проверка
  `treeMenuEl!==m`, снятие с теми же флагами (contextmenu — capture).
- **Слушатель contextmenu вешать один раз** (флаг `treeCtxBound`),
  не в каждом `renderTree()` — иначе плодятся дубли меню.
- **Вкладка «Группы» не видит изменения**: после любой мутации
  структуры звать `uiStructureChanged()`, а не только `renderTree()`.
- vim-строка в index.html должна стоять ПОСЛЕ `<!doctype html>` и быть
  HTML-комментарием — текст до doctype включает Quirks mode и
  рендерится в угол страницы.
